# Earthquake risk map

🔗 **サイトURL: https://earthquake-risk-map.onrender.com**

日本周辺の地震活動を、気象庁(JMA)・P2P地震情報・USGSなど複数の公的データソースを使って
可視化する研究用Webサイトです。地震そのものの履歴に加えて、ETAS解析やb値解析、
活断層・プレート境界への応力負荷などを統合した「相対リスク指数」マップも見られます。

> ⚠️ **このサイトについて**
> ここで表示される「リスク指数」はあくまで統計的な相対指標であり、
> **地震の発生確率や予知を意味するものではありません**。研究・興味本位での閲覧を
> 想定した非公式のプロジェクトです。防災に関する判断は、必ず気象庁など公的機関の
> 発表を確認してください。

## サイトの見方（左メニューのタブ）

### 地震データ

- **統合リスクマップ**（初期表示タブ）
  ETAS・b値・活断層・プレート境界・気圧偏差などを重み付けして合成した相対リスク指数を、
  地図上に5段階（Lv1〜Lv5、水色→黄→赤→紫→黒の順で高リスク）の色分けで表示します。
  画面上部の「プリセット」ボタン（標準／全データ／地質／地殻変動／カスタム）で
  使用するデータの組み合わせを切り替えられ、セルをクリックするとその内訳が見られます。
  ※ TEC・GNSSは現在「近日公開」で、まだこの合成指数には含まれていません。
- **地震履歴**
  JMA・P2P地震情報・USGSのデータを統合し、有感・無感を問わず地震の一覧と発生地点を表示します。
- **ETASマップ**（研究用）
  ETASモデル（Ogata, 1998）による地震活動度の相対評価です。
- **b値マップ**
  グリッドごとのGutenberg-Richter b値（地震の規模別頻度分布の傾き）を表示します。
- **活断層・プレート境界**
  都市圏活断層図・プレート境界（GEMデータ）を地図に重ねて表示します。

### 地球物理データ

- **TEC**（電離圏全電子数）
  NICTのSCIDASへのリンクを掲載しています。
- **GNSS変位**
  国土地理院(GSI)の電子基準点データによる地殻変動ベクトルです。
  実データが未設定の場合はプレースホルダー表示になることがあります。

### 気象

- **海面気圧**
  アメダスの観測データによる海面気圧マップです。

### ログ

- **アーカイブ**
  日付と時刻を指定すると、その時点を基準に過去1か月分の地震データから
  統合リスクマップを再現できます。
  - 直近60日以内の日時 → JMA・P2P統合データ（高精度）を使用
  - それより古い日時（数年前まで指定可能）→ USGSの過去カタログから取得
    ただしUSGSは国内の小規模地震まで網羅していないため、古い時期ほど
    小さな地震が結果に含まれない場合があり、震度情報も表示されません。
    画面の「データソース」表示でどちらが使われたか確認できます。

## データの更新頻度

地震データはサーバー側で約10分ごとに自動更新されます。各タブの画面下部・
右上などに表示される「更新: ...」の時刻が最終更新のタイミングです。

## データ出典

- 地震データ: 気象庁(JMA) / [P2P地震情報](https://www.p2pquake.net/) / [USGS](https://earthquake.usgs.gov/)
- 活断層・プレート境界: GEM（Global Earthquake Model）
- 電離圏: NICT SCIDAS
- 地殻変動: 国土地理院(GSI) GEONET
- 気圧: アメダス(AMeDAS)
